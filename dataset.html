DATASET RELEASE

Agent Selection under Heterogeneous Objectives

Dataset entry established; task archive forthcoming.

The current website publishes experimental results, diagnostic tables, and curated case studies. The full task-package archive will be added in a subsequent data release.

Native execution evidence is organized into related selection instances with explicit acceptance targets, cost budgets, and time limits. The current research snapshot covers nine task families, 1,116 source tasks, 1,180 packages, and 22,240 constrained scenarios.
